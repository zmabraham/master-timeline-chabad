# Master Timeline Chabad

A zoomable, searchable, multi-level timeline of Chabad history (English-only v1) built from a consolidated corpus of existing extractions, the book *Undaunted*, the 17 Chabad Library *Misaviv L'Chassidus* history books, and Chabadpedia.
