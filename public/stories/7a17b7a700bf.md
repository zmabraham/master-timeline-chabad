# Library acknowledges Iyar 5693 book donations

*1933*

Using letterhead headed 'Aseifas Sefarim u'Kisvei Yad Lubavitch — temporarily in Riga, Latvia,' the Rebbe acknowledged a recent shipment with thanks. The stationery, envelopes and postcards bearing this header were one of several mechanisms — alongside newspaper advertisements — used to formalize the library as an institution rather than a private collection.
