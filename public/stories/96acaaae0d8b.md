# Rabbinic conference establishes 'Vaad HaChevronim' to expand pushke network

*1905*

The conference, later described by Rebbe Maharayatz, sought ways to improve the income flowing to Kollel Chabad through R. Meir Baal HaNes pushkes. Rebbe Rashab concluded that a specialized oversight body, named the 'Chevronim', was needed to closely monitor donations. The vaad's first priority was to install pushkes in every Jewish home across Russia.
