# Soviet Scientific Council refuses to return Schneersohn library

*1924*

The response cited decisions of 16 December 1919 and 21 May 1921 as basis for the transfer by Narkompros. It was signed by Pinkevich, acting chairman of the Scientific Council, and Zinkov, chairman of scientific libraries. This refusal prompted the Rebbe to file another similar request in winter 5685.
