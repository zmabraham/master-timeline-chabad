# Russian Supreme Court appeal hearing on the Schneerson library

*1991*

State Library staff packed the courtroom while about ten counter-protesters with anti-Chasidic placards demonstrated outside, a few hurling Nazi-style epithets at arriving Chabad supporters. Attorney Veronika spoke for Chabad along with the bibliographic expert Yakirson, while the library directors struggled to produce documentation of any nationalization. The chief justice announced the ruling would come the next day.
