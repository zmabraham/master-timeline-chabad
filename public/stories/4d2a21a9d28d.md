# Khovansky requests Mitteler Rebbe case file with summary

*1827*

On March 2, 1827, from Vitebsk, Khovansky directed the First Department of the Mogilev High Court to send him the verdict in the Mitteler Rebbe case together with the original file and a concise summary as soon as possible. The court initially responded on March 22 with the requested materials, but Khovansky pressed again on March 29 before being informed on April 13 that everything had already been dispatched. The case would eventually be escalated to the Senate in Petersburg on appeal.
