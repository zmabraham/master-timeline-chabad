# "Jerusalem will yet need to be liberated anew" — so she wrote in a letter

*1987*

"Jerusalem will yet need to be liberated anew" — so she wrote in a letter to the Rebbe in 5747, and so she recounted in a video interview. The text of the letter was printed in the Chadashot newspaper, 3 Nissan 5747 (April 2, 1987)
