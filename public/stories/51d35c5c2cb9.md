# GPU misreads coded letter on Vitebsk visa list for 15 bochurim

*1931*

Shortly before Purim 5691 the Vitebsk hanhala received word from R' Yehuda Eber that visas were being arranged in Riga for 15 bochurim, with the message written in tiny letters as '15 ס.' to disguise the request. The hanhala understood that 'ס' stood for 'simanim' meaning bochurim, but when the GPU showed the letter to imprisoned balei-batim and an elderly chassid foolishly explained the code, the gentile investigator triumphantly identified the plot. The chassidim involved were held in prison for a long time.
