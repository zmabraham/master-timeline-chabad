# Soviet TV channel TCH airs false report of judge retracting library ruling

*1991*

When the broadcast reached Gribenikov he issued a strong protest, which TCH and the Vesti network agreed to air in correction. Around the same time, Culture Minister Gubenko reportedly decided to dismiss library director Vyalik for cooperating with the court's order to return the books to Chabad, raising the stakes of the unfolding struggle.
