# Rebbe Rayatz proposes R' Yitzchak Dov Oshpal for Braslav branch

*1934*

Discussions arose in spring 5694 about opening a new Tomchei Tmimim branch in Braslav. R' Yitzchak Dov Oshpal was among the candidates proposed to lead it. Though the Braslav branch ultimately never opened, this exchange set the stage for his appointment as Rosh Yeshiva in Vilna the following year.
