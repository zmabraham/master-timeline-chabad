# Third Mechina class added; classes split between Twarda and Zamenhof

*1933*

Class A learned at Twarda (Proste 10) and Classes B–C at Zamenhof 8. R' Yehuda Eber reported tighter admissions standards had slightly lowered numbers but expected the Twarda branch to grow. Around the same time R' Mordechai Mentlik joined the staff as maggid shiur for the youngest class.
